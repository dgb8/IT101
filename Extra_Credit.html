5 Good Practices for Webpage Design

  1. Make certain the webpage will be properly formatted on multiple devices and screens.
  2. Include <alt> text for people with disabilities.
  3. Make the color scheme of the webpage pleasant to look at.
  4. Ensure that the user can easily navigate through the website.
  5. Ensure that the user can get back to the main page from any part of the website.

5 Bad Practices for Webpage Design

  1. Overly using flashy images.
  2. Using a text font that is hard to read.
  3. Using font and background colors that make it hard to read the font.
  4. Not including ways to get back to the main webpage from all other parts of the website.
  5. Making your webpages too cluttered.
